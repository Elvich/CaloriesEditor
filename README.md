# CaloriesEditor 🍏

Простое приложение для отслеживания калорий, написанное на **SwiftUI**.

## Особенности
- Отслеживание приемов пищи и калорийности.
- Хранение данных (вероятно, SwiftData/CoreData на базе `Item.swift`).
- Минималистичный интерфейс.

## Технологии
- **SwiftUI**
- **SwiftData** (или CoreData)
- **Xcode 15+**

## Как запустить
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Elvich/CaloriesEditor.git
   ```
2. Откройте `CaloriesEditor.xcodeproj` в Xcode.
3. Нажмите **Cmd + R**, чтобы запустить проект в симуляторе.
